# Insurance Charges Analysis & Prediction

## About the Project

This project focuses on understanding what factors are related to medical insurance charges and using those factors to predict insurance costs.

I worked on the project from data exploration to model evaluation, including data preprocessing, feature engineering, handling skewed data, and building regression models.

## Dataset

The dataset contains information about insurance customers, including:

- Age
- Sex
- BMI
- Number of children
- Smoking status
- Region
- Insurance charges

## What I Did

- Explored the dataset and analyzed the distribution of different variables.
- Used visualizations to understand the relationship between customer characteristics and insurance charges.
- Performed data preprocessing and feature engineering before building the models.
- Used Box-Cox transformation to handle skewness in the data.
- Built regression models to predict insurance charges.
- Compared model performance using R², MAE, and RMSE.
- Used cross-validation to check how consistently the models performed.
- Created a Power BI dashboard to explore insurance-charge patterns.

## Results

The regression models achieved an R² score of around **0.85** on the evaluated data.

The notebook contains the detailed model evaluation and comparison.
